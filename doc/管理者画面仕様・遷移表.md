# Re:Tailor 管理者画面仕様・遷移表

最終更新日：2026年9月29日

## 1. 前提

管理者画面は今回の要件書に記載された追加プロトタイプであり、既存サイトマップ・画面設計書に管理者用の定義はない。そのため、一般画面の既存導線を維持し、トップ画面のドロワーメニューに「管理者ログイン」を追加する。認証・管理データは `localStorage` による仮実装で、実運用の認証・データベース連携は行わない。

## 2. 表示・操作ルール

- デスクトップでは最大幅1400px、左ナビゲーション付きで表示する。幅980px以下では一覧を項目ラベル付きカードに切り替えて全項目を保ち、幅700px以下ではナビを複数行にする。最小確認幅は320px。
- 既存画面と同じ白・黒／濃いグレー・オリーブ系、日本語フォント、角丸4px以下を基本とする。
- 一覧の初期データは画面確認用の仮データ。変更内容は同一ブラウザーの `localStorage` に保持する。
- 商品画像は実画像未連携のため、カテゴリ文字を使った仮表示と読み上げラベルを表示する。
- 編集フォームのキャンセル、詳細の戻る操作はそれぞれ表の遷移先に従う。削除は確認ダイアログでキャンセル可能。
- 管理画面の各ページは未認証時にログインへ戻し、ログアウト後も直接URLで閲覧できない。
